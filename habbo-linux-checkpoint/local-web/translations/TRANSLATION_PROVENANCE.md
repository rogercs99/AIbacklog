# Habbo ES translation provenance

Generated 2026-09-24 for the local Chrome/Safari adaptation.

Sources used only as value dictionaries; runtime keys/order remain those of the project:
- Archived Habbo Spain external texts (`habbo.com.es.txt`) from h4bbo.net archive.
- Historical V3.1-era Spanish external text dump from habbo--marino.es.tl.
- Machine translation only for keys not covered by those archives, with placeholders masked and exact token equality required before acceptance.

Safety/integrity rules:
- keys are never translated or renamed;
- URLs/codes/assets are not machine-translated;
- placeholders such as `%...%`, `${...}`, `\\r`, `\\n`, `\\x` are preserved;
- proper names/brands/venue names are kept when appropriate;
- no credentials, SSO tickets or secrets are included.
