Version control for proposal drafts  Within the writing canvas, the   “ Version History ”   button displays the different backups that  have been created for each section of the proposal. Each version shows the date and time  when it was saved, a summary of the version, and the user who generated it.  Saved versions can be automatic or manual.  •   Automatic versioning   is performed periodically every   10 seconds   by aXet.bid,  without requiring any user intervention, as long as a change has been made to the  text. These backups are iterative and are stored up to a maximum of 10 versions.  Once this limit is reached, the newest copy will replace the oldest one.
•   The second type,   manual versions , are created at the explicit request of the user,  who can assign them a name and a description.  When the user opens the history and clicks on a saved version, the text is loaded into the  writing canvas. If the user then modifies the loaded text, it will automatically become the  current version. The   documents indexed   in aXet.bid through the   SharePoint synchronization  mechanism   have a   default validity period of 90 days .   The expiration time of each  file is displayed using a colored label that shows the number of days remaining before  it is de - indexed.  This validity   counter is reset individually to 90 days for each file   every time a query  or an operation   is made that, in order to be answered, requires the information  contained in that document.  If the configured time period expires without any query being made to aXet.bid that  requires that document, its   indexed information will be released   in order to  optimize the use of the infrastructure.  If this happens and the user needs to   recover expired documents , they can do so  from the " Expired " option. This   option   will display a list of all files whose contents  have been removed from the RAG, allowing their content to be re - indexed as long as  the original document   still exists in SharePoint .
There are three   actions   in this section:  •   Individual deletion : Deletes the document and it can no longer be restored  or viewed.  •   Recovery : Restores the document, making it appear again in the document  tree with its retention period fully renewed, 90 days.  •   Clear all : Clears all records from this modal and, just like individual deletion,  they can no longer be restored or viewed.  •   Response   Hub :   Activate   the   Response   Hub,   a   comprehensive   collective  knowledge repository   designed to enhance your proposals by providing access to  frequently asked questions, user - generated responses, and detailed usage metrics.  You can filter questions by most recent or oldest, or search directly using keywords.
